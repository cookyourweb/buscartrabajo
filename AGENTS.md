# Agents

The rules of this project are in **[CONTRIBUTING.md](CONTRIBUTING.md)**, and they
apply equally to a person and to an agent.

SDD activo:
- Lee `docs/constitution.md` y la spec activa (`specs/NNN-*/`) antes de tocar código.
- Tests: `npm test` (y los específicos del área afectada).
- Tras cada cambio, verifica con Chrome DevTools, incluyendo móvil.
- Secretos solo por entorno; nunca tokens en repo.

This file exists only because some tools load it on their own. It adds no rules: if it
ever contradicts `CONTRIBUTING.md`, the other one wins.
